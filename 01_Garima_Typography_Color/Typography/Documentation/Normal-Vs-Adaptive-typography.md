# Adaptive Typography — Normal and Adaptive States

## Purpose

This document explains how the dashboard typography differs between the Normal and Adaptive states. The comparison focuses on text presentation while keeping the dashboard content and overall structure consistent.

## Normal Typography

The Normal state represents the baseline dashboard with standard text sizes, weights and spacing.

**Evidence:** `../UI/Normal Typography Dashboard.png`

## Adaptive Typography

The Adaptive state explores changes in typography to support a more flexible reading experience. The dashboard layout and content remain familiar while selected text properties are adjusted.

**Evidence:** `../UI/Adaptive Typography-Dashboard.png`

## Typography Changes

### Headings and Labels

- Headings and labels use distinct text styles.
- The Adaptive state explores changes in size and weight.
- The relationship between different text levels is preserved.

### Metric Values and Supporting Text

- Metric values remain visually distinct from their labels.
- Supporting text stays connected to the relevant metric.
- Typography adjustments are explored without changing the information presented.

### Line Height and Letter Spacing

- The Normal state uses the baseline spacing.
- The Adaptive state explores increased line height and letter spacing where appropriate.
- Text remains within its component boundaries.

### Font Width and Optical Size

- The design explores width and optical size when supported by the selected variable font.
- These properties are considered alongside font size and weight.
- Their use depends on the selected font and the needs of the design.

### Tables and Dashboard Components

- The same table content and dashboard components are retained.
- Typography changes are reviewed for clipping, overlap and overflow.
- Navigation and the overall dashboard structure remain consistent.

## Design Rationale

The purpose of Adaptive Typography is to explore how text presentation can change without redesigning the entire interface. The comparison helps show the role of font size, weight, spacing and variable font properties while maintaining a clear information hierarchy.
