# Cognitive Accessibility Prototype

## Purpose

This prototype demonstrates how the Chameleon dashboard can adapt when a higher cognitive-load condition is detected.

The cognitive-load condition is **simulated in Figma**. No real cognitive-load, biometric, or medical detection is implemented.

## Prototype Flow

Normal Dashboard UI
→ High Cognitive Load Detected
→ Normal Dashboard - Cognitive Transition
→ Cognitive-Friendly Dashboard UI

## Interaction Sequence

1. The normal dashboard is displayed.
2. After a short delay, a small **High Cognitive Load Detected** overlay appears.
3. The overlay communicates that the interface is switching to a focused view.
4. The overlay disappears.
5. The dashboard transitions from the normal state to the cognitive-friendly state using Smart Animate.

## Adaptive State

The Cognitive-Friendly Dashboard preserves the core dashboard information while reducing unnecessary visual competition and improving scanability.

## Prototype Scope

This prototype demonstrates the proposed adaptive interaction in Figma. The detection condition is simulated for demonstration purposes.
