# Cognitive Module — Final Review Evidence

## Module Story

**Problem**
Complex dashboards can contain multiple competing visual elements and changing information.

**Research**
Cognitive accessibility research informed the focus on visual noise, information priority, structure, focus, clarity, and familiarity.

**Wireframes**
Normal and cognitive-friendly dashboard structures were planned before UI refinement.

**UI**
The Cognitive-Friendly Dashboard preserves essential information while reducing redundancy and visual competition.

**Prototype**
A simulated high-cognitive-load condition transitions the dashboard into the cognitive-friendly state.
