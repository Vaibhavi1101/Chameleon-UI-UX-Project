# Cognitive Dashboard Design System

## Typography

Primary typeface: **Inter**

Key dashboard sizes used across the design include:

- 11–12 px — supporting metadata
- 13–14 px — labels and secondary information
- 16–18 px — section headings
- 28–30 px — primary dashboard metrics/headings

## Spacing

The dashboard follows an 8-point spacing approach, using values such as:

`8 / 16 / 24 / 32 px`

## Radius

Common component radii include:

`10 / 12 / 16 px`

## Cognitive-Friendly Adaptations

The adaptive state uses the same design system rather than introducing a separate visual language.

Adaptations include:

- removing redundant KPI sparklines
- strengthening primary metric hierarchy
- increasing separation between chart bars
- clarifying activity text hierarchy
- improving transaction scanability
- preserving familiar navigation
- using the Focus Mode indicator to communicate the active state
